# Banking System 🏦

Проект представляет собой глубоко проработанную логику банковского ядра, построенную на принципах объектно-ориентированного программирования. Система реализует управление различными типами счетов с уникальной бизнес-логикой, строгой валидацией и многоуровневой защитой данных.

---

## 🏗️ Архитектура и модульность

Проект имеет модульную структуру, обеспечивающую чистоту кода и легкость масштабирования. В основе лежит иерархия классов, где базовые абстрактные классы определяют общие контракты, а дочерние классы реализуют специфику конкретных банковских продуктов.

### Реализованные типы аккаунтов:

1.  **SavingAccount (Сберегательный):**
    *   Контроль `Min_balance` — минимально возможного остатка на счете.
    *   Учет месячной ставки доходности.
    *   Реализован метод для расчета прибыли за месяц.
2.  **PremiumAccount (Премиальный):**
    *   Увеличенные лимиты на операции.
    *   **Возможность овердрафта:** баланс счета может уходить в отрицательное значение.
    *   Применение фиксированной комиссии за обслуживание.
3.  **InvestmentAccount (Инвестиционный):**
    *   Управление инвестиционными портфелями.
    *   Работа с виртуальными активами, приносящими пассивный доход (stocks, bonds, etf).
    *   Метод `project_yearly_growth` для вычисления ежегодной прогнозной доходности от активов.

---

## 🛡️ Безопасность и Валидация

Система спроектирована с упором на отказоустойчивость и защиту от некорректных действий:

*   **Статусы счета:** Внедрена проверка состояний (Замороженный, Активный, Закрытый). Операции блокируются, если статус счета не позволяет их проведение.
*   **Валидация ввода:** Строгие проверки на корректность сумм, поддержку разных валют и защиту от несанкционированных отрицательных значений (кроме разрешенного овердрафта).
*   **Custom Exceptions:** Реализованы собственные классы ошибок для точной обработки исключительных ситуаций (некорректная сумма, нарушение статуса счета и др.).

---

## ⚙️ Полиморфизм и реализация методов

Каждый новый класс переопределяет ключевой функционал для корректной работы системы:
*   `Withdraw()` — логика снятия средств, адаптированная под правила конкретного счета.
*   `Get_account_info` — предоставление подробных данных о состоянии и параметрах аккаунта.
*   **Вывод класса при печати:** переопределение метода для наглядного отображения информации об объекте в консоли.
